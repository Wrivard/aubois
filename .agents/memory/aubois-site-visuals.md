name: Service d’Arbres Aubois visual rules
description: Preserve the site layout and use original no-person illustrative imagery.
---

Keep the existing site design and layout unchanged unless the user approves a layout change. When replacing website photos, use original generated visuals and include no people. Describe generated gallery images as illustrations, not as photos of completed client jobs.

**Why:** The user asked to preserve the design and requested imagery that is original to this site with no people; disclosing illustrative imagery avoids implying these are documented projects.

**How to apply:** Make content and image updates within existing sections. Ask before changing the page structure or visual layout.
